# Lyriq AgentOS

Prototype visual do Lyriq AgentOS, um sistema operacional baseado em Linux para apps, agentes, provedores de IA e runtime nativo da Lyriq.

## Rodar local

```bash
npm install
npm run dev
```

## Estrutura

- `src/`: prototipo navegavel
- `design/reference/`: imagens e referencias visuais do design aprovado
- `public/assets/`: assets usados pelo app
